# 宝宝英语陪伴乐园

一个面向 3 到 6 岁儿童的亲子 AI 英语陪伴网页。它不是传统背单词软件，而是让 Teddy 小熊每天陪孩子用 10 到 15 分钟轻松学英语。

## 功能

- Teddy 小熊英语伙伴
- 固定每日流程：Hello、3 个新词、小游戏、跟读、奖励、Bye bye 报告
- 每天只展示 3 个生活化单词
- 每屏 2 到 4 个大按钮，适合手机、平板和电脑
- 即时正反馈：Good job、Excellent、You did it
- 星星、贴纸、连续学习天数
- 家长陪学建议
- 每日成长报告
- 500+ 基础词汇作为后续内容库
- 每个单词都有独立儿童图标
- 家长区支持本地自定义词库和导出备份
- 可直接放到 GitHub Pages

## MVP 学习流程

1. Teddy 问候孩子。
2. 认识今天 3 个新单词。
3. 玩“Can you find...”找图片游戏。
4. 跟 Teddy 做一次口语跟读。
5. 领取星星和贴纸奖励。
6. 生成今日成长报告和家长陪练任务。

## 怎么分享

1. 把这个文件夹上传到 GitHub 仓库。
2. 在仓库设置里打开 GitHub Pages。
3. 选择根目录发布，保存后就能分享链接。

## 怎么继续加词

- 直接编辑 `data/vocabulary.js`
- 或者在网页里的“家长更新区”先加词，再导出备份

## 本地打开

如果你想先在本机看效果，直接用任意静态服务器打开这个目录即可。

## 备注

这个版本故意把孩子端做得很简单，目标是让孩子愿意每天打开，而不是一次学很多。

单词图标匹配参考了 MIT 许可的 `emojilib` 关键词数据。
